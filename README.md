# Xiawan Workflow Plugin

Xiawan Workflow Plugin 是一个面向 ComfyUI 的工作流扩展插件，提供完整的文生图、图生图、控制图、放大、局部细化和显存管理能力。项目同时集成了 LoRA 管理、提示词编辑、Danbooru 标签处理、Anima 模型支持以及一套可直接使用的生产级工作流。

## 主要功能

- 支持 SDXL 主采样链和 Anima 分支，并提供全局 Seed 管理。
- 支持 OpenPose、Scribble、Lineart、Depth 和 IPAdapter 等控制方式。
- 支持潜空间放大、迭代放大、模型放大以及脸部、眼睛、手部、足部等区域细化。
- 提供 Tiled VAE、显存预检、模型卸载和阶段性显存释放工具，适合显存有限的设备。
- 集成 LoRA 加载、触发词管理、提示词选择器和 WeiLin 提示词编辑器。
- 支持 Danbooru 标签反推、提示词清洗、图像保存、元数据记录和结果对比。
- 内置 Anima Qwen3 0.6B + T5 文本编码器兼容实现。
- 选择性内置 ControlNet Auxiliary、Impact Pack、IPAdapter、Mira、LoRA Manager 和 WeiLin Tools 等运行时组件。

## 项目结构

```text
__init__.py              ComfyUI 节点入口和节点注册
func_upgrades.py         显存管理、性能保护和功能增强节点

web/                     ComfyUI 前端扩展
```

## 安装

将整个项目目录放入 ComfyUI 的 `custom_nodes` 目录：

```text
ComfyUI/custom_nodes/comfyui_xiawan's-workflow_plugin
```

根据本地 ComfyUI、PyTorch 和 CUDA 环境安装所需依赖，然后重新启动 ComfyUI。项目的第三方依赖清单位于 `vendor/` 下对应组件的 `requirements.txt` 文件中。

## 使用

1. 启动 ComfyUI。
2. 在节点菜单中查找 `Xiawan` 分类及已注册的兼容节点。
3. 打开 `workflows/Xiawan's Workflow ver.R-1.0.json`。
4. 根据本地模型目录调整 Checkpoint、LoRA、VAE、ControlNet 和 Anima 模型名称。
5. 通过左侧控制节点启用或关闭底图、控制、放大和细化阶段，然后执行工作流。

## 工作流操作说明

主工作流分为三类区域：开关区、参数控制区和逻辑区。日常使用时只需要操作前两类区域。

> **重要：不要随便调整“逻辑区”**
>
> 逻辑区是工作流的内部执行结构，负责采样主链、控制图分支、放大与输出、细化连接、开关状态读取和显存释放。请不要在逻辑区内随意移动、删除、复制、重命名或重新连接节点，也不要修改其中的 `GroupIsEnabled`、`GroupIgnoreManager`、采样节点、切换节点和显存管理节点。除非你明确了解整个连接关系，否则只通过开关区和参数控制区改变工作流行为。

### 一、开关区

开关区位于工作流左侧，包含三个面板。

#### 1. 文生图主链路

- **总开关**：控制整套文生图工作流。初次排查问题或只想查看参数时，可以关闭它。
- **0-i SDXL 底图**：使用 SDXL 作为底图生成分支。常规 SDXL 工作流应开启此项。
- **0-ii Anima 底图**：使用 Anima 作为底图生成分支。SDXL 和 Anima 是互斥选择，不建议同时开启。
- **1 潜放**：启用潜空间放大阶段。
- **2 迭代**：启用迭代放大阶段。
- **3 通用**：启用通用模型放大阶段。
- **4 细化**：启用局部区域细化总开关。

建议先只开启一个底图分支，确认基础图像正常后，再逐项开启放大或细化阶段。多个高显存阶段同时启用时，运行时间和显存占用都会增加。

#### 2. 可选功能

- **0-a OpenPose**：根据参考图控制人物姿态。
- **0-b 人物替换**：使用人物参考图辅助身份、服装或外观重绘。
- **0-c1 Scribble**：使用草图或涂鸦控制结构。
- **0-c2 Lineart**：使用线稿控制画面轮廓。
- **0-c3 Depth**：使用深度图控制空间层次。
- **0-d 图像反推**：从输入图像提取 Danbooru 标签或提示词。
- **0-e D 站画廊**：使用 Danbooru 画廊选择参考图或标签。

启用某个可选功能后，再到对应的参数控制区加载参考图、设置强度或检查预览。没有对应输入图时，不要开启相关控制分支。

#### 3. 细化子项

- **总开关**：控制全部局部细化阶段。
- **4-a**：脸部细化。
- **4-b**：眼睛细化。
- **4-c**：手部细化。
- **4-d**：足部细化。
- **4-e**：乳首细化。

建议只开启确实需要的区域。人物较小、检测器不匹配或显存不足时，应先关闭不必要的细化子项。

### 二、参数控制区

#### 1. 模型、LoRA 和底图参数

该区域位于 `0 模型 / LoRA / 底图参数` 分组。

- **Checkpoint**：选择 SDXL 主模型。
- **Refiner Checkpoint**：只有启用 Refiner 时才需要配置。
- **LoRA**：添加 LoRA、调整权重，并通过触发词节点控制触发词是否参与提示词。
- **全局 Seed**：设置基础 Seed 和运行方式。常用方式包括固定、随机、递增、递减和沿用上次 Seed；`current_seed` 是运行结果显示值，通常不需要手动修改。
- **SDXL 主参数**：设置批次数量、采样步数、CFG、采样器、调度器、主采样降噪、Refiner、底图模式和是否保存图像。
- **Anima 主参数**：设置 Anima 分支的宽度、高度、批次数量、步数、CFG、采样器和调度器，仅在 Anima 分支开启时生效。
- **全局分辨率**：统一设置工作流的目标宽高。建议优先通过此节点调整尺寸，不要分别修改逻辑区中的空 Latent、采样或解码节点。
- **底图输入 / 图生图编码**：进行图生图时加载输入图，并使用图生图尺寸对齐和编码参数；纯文生图时不要开启相关图生图路径。
- **质量增强 FreeU/PAG**：用于调整 FreeU 和 PAG 的增强参数。出现过度锐化、细节异常或风格变化时，应降低强度或关闭增强。
- **Tagger 配置**：用于图像反推的模型、阈值、标签类别、排除标签和运行设备设置。
- **提示词 A/B**：用于快速比较两组提示词。选择 A 或 B 后再执行工作流，适合测试构图、风格和细节差异。

首次使用时，建议先完成模型、LoRA、分辨率和 Seed 配置，再设置采样参数。若显存有限，优先降低批次数量和分辨率，然后再减少采样步数。

#### 2. 提示词编辑

该区域位于 `提示词编辑` 分组。

- **正面提示词**：填写主体、人物、服装、动作、环境和画面风格。
- **负面提示词**：填写希望避免的画面问题，例如低质量、畸形手部、额外肢体、文字和水印。
- **固定前缀**：放置每次生成都需要保留的质量或风格标签。
- **固定后缀**：放置每次生成都需要追加的通用标签。
- **自动随机**：只有配置了随机模板时才启用；启用后每次执行可能产生不同提示词。

提示词编辑器的输出会连接到后续编码节点。修改提示词时只编辑文本内容，不要删除其输出连接或替换为不兼容的节点类型。

#### 3. 姿态、人物和结构控制参数

该区域位于 `0-a~0-c3 姿态 / 人物 / 结构控制` 分组。

- **控制参数**：分别调整 OpenPose、Scribble、Lineart、Depth 和人物参考的强度。
- **开始 / 结束**：控制对应条件在采样过程中的介入区间，通常使用 `0` 到 `0.85` 或类似的渐进范围。
- **参考图输入**：为 OpenPose、人物参考和结构控制加载图片。
- **预览节点**：查看预处理后的控制图；它们用于检查效果，不需要手动接线。
- **扩图蒙版支架**：需要扩图或局部垫图时设置边距和蒙版颜色；普通文生图保持关闭或保持默认值。

启用控制分支后，先检查预览结果，再逐步增加控制强度。控制图内容不符合预期时，应先修正输入图或预处理方式，不要直接修改逻辑区连接。

#### 4. 图像反推和 D 站画廊

该区域位于 `0-d~0-e 图像反推 / D 站画廊` 分组。

- **图像反推**：加载输入图，设置 Tagger 参数，执行后查看标签预览，再将需要的标签整理到正面提示词中。
- **D 站画廊**：选择或浏览参考图，并查看生成的提示词预览。
- 图像反推和画廊属于可选输入流程，不需要时保持对应开关关闭。

#### 5. 放大和局部细化参数

该区域位于 `1-4 放大细化` 分组。

- **最终输出选择**：选择工作流最终输出的阶段。
- **1 潜放参数**：设置潜空间放大算法、放大倍率、采样步数、CFG、采样器、调度器和降噪。
- **2 迭代参数**：设置迭代放大方式、放大倍率、迭代次数、每步采样参数以及是否使用 Tiled VAE。
- **3 通用放大参数**：设置放大模型、放大倍率、目标倍率、采样步数、CFG、采样器、调度器和降噪。
- **VAE 分块参数**：大图或显存不足时启用 Tiled VAE，并调整分块大小和重叠区域。
- **4-a 到 4-e 细化参数**：分别设置检测模型、步数、CFG、降噪、采样器、调度器、引导尺寸、最大尺寸、羽化、检测阈值、裁剪倍率、噪声遮罩和区域提示词。
- **保存元数据 / 保存最终图像**：配置文件名前缀、图像格式、质量、工作流嵌入和最终保存行为。

推荐顺序是先验证底图，再单独测试一种放大方式，最后根据需要开启局部细化。细化参数中的检测模型必须与目标区域匹配，否则可能没有检测结果或产生错误区域。

### 三、推荐使用流程

1. 打开主工作流并检查模型文件名是否存在。
2. 在“文生图主链路”中选择 SDXL 或 Anima，只开启一个底图分支。
3. 在模型、LoRA、Seed、分辨率和采样参数区完成基础配置。
4. 在提示词编辑区填写正面和负面提示词。
5. 如有需要，再开启 OpenPose、人物参考、Scribble、Lineart、Depth、图像反推或 D 站画廊。
6. 先生成并确认底图正常，再开启潜放、迭代、通用放大或局部细化。
7. 显存不足时优先关闭不必要的开关、降低批次数量和分辨率，或启用 Tiled VAE。
8. 始终通过开关区和参数控制区调整行为，不要直接修改逻辑区。

## 运行要求

- ComfyUI 及其基础 Python 运行环境。
- 与 ComfyUI 匹配的 PyTorch 和 CUDA 环境（如使用 NVIDIA GPU）。
- 工作流所需的 Checkpoint、LoRA、VAE、ControlNet、检测器和 Anima 模型。
- 部分内置组件需要额外的 Python 依赖，详见 `vendor/` 下的依赖文件。

## 模型权重说明

仓库不提交体积较大的 ControlNet Auxiliary `.pth` 权重文件，以避免超过 GitHub 单文件和仓库存储限制。使用相关预处理器时，请按照 ComfyUI 或对应组件的模型下载方式获取权重，并放入本地 `vendor/controlnet_aux/ckpts/` 或 ComfyUI 配置的模型目录。源码、前端资源、工作流和必要的小型配置文件仍包含在仓库中。

## 工作流说明

项目提供的主工作流包含 SDXL 和 Anima 两条底图路径，并连接了提示词编辑、姿态/结构控制、图像反推、放大、局部细化、资源释放和最终保存等阶段。完整的连接检查和运行记录见 `workflows/Xiawan_Function_Connection_Test_Report.md`。
